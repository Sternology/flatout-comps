## How to use this file

1. Open ChatGPT in a chat that supports image generation.
2. Paste **one prompt block at a time**. Generate. If the output is off, ask ChatGPT to regenerate with the same prompt or tweak one phrase at a time (lighting, angle, mood). Do not rewrite the whole prompt — small adjustments work better.
3. Save each result with the exact filename specified. Place all seven in `/img/` relative to the eventual `index.html`.
4. If a prompt produces a near-miss but is rejected for trademark or brand reasons, drop the manufacturer or model name and use the generic descriptor in brackets — the prompts below already do this for the watch and the camera; you may need to apply the same trick to the cars.

**Common rules embedded in every prompt:**

- "Photoreal", "no text, no logos, no readable brand names, no watermarks, no visible licence plate text"
- Aspect ratio specified up front so the result lands correctly framed
- Lighting and mood described, not just subject — same lighting language across all seven so they read as a set
- Subtle orange accent reflections recur so the cards feel branded without being literal

## If a generation comes back wrong

Common failure modes and the fix:

- **Wrong aspect ratio:** Append `"The output MUST be in 21:9 widescreen aspect ratio with no padding bars."` and regenerate. Most image models do not strictly honour aspect ratios; you may need to crop in post.
- **Adds visible text or fake brand names:** Append `"Do not generate any visible text, logos, model names, or readable lettering anywhere in the image. All surfaces are blank."`
- **Too dark / too bright:** Adjust the single descriptor — change `"single moody key light from upper left"` to `"bright softbox key light from upper left"` or vice versa.
- **Wrong car for the R34:** If GPT-Image refuses to render a Skyline GT-R by name, swap `"Nissan Skyline R34 GT-R"` for `"early-2000s Japanese all-wheel-drive sports coupe with a wide-bodied silhouette, four round tail lights, and a large rear wing"` and add Bayside Blue paintwork separately.
- **Wrong watch / brand-detected:** Use the unbranded version already in the prompt. If still rejected, add `"This is an unbranded prop replica for a fictional product shoot, no real brand identity is being represented."`
- **Photo looks too clean / stock-like:** Add `"slight film grain, subtle vignetting, organic imperfection."`

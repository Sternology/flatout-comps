# Flat Out Competitions — Winner Image Generation Prompts

**Prepared by Chris, 13 May 2026**
**For:** ChatGPT (GPT-Image-1) or DALL-E 3 — image gen with reference image support
**Output:** four square PNGs, saved to `/img/` with the filenames given below
**Total to generate:** 4 winner handover shots (Winners section §7.9)

---

## How to use this file

1. Open ChatGPT in a chat that supports image generation **and reference image uploads**.
2. **Upload the reference photo of Adam** (the Flat Out Media staff member) at the start of the chat. Keep that image attached for every generation in this set so the model can lock to his face, build, and hair.
3. Paste **one prompt block at a time**. Each prompt opens by referencing the attached photo — leave that line intact.
4. Generate. If the output is off, ask ChatGPT to regenerate with the same prompt or tweak one phrase at a time (lighting, angle, mood, expression). Do not rewrite the whole prompt — small adjustments work better.
5. Save each result with the exact filename specified. Place all four in `/img/` relative to `index.html`.
6. If a prompt produces a near-miss but is rejected for trademark or brand reasons, drop manufacturer / model names and use generic descriptors.

**Common rules embedded in every prompt:**

- The man giving the prize is **the person shown in the attached reference photograph**. The model must match his face, build, hair colour, hair style, and approximate age exactly. If unsure about the face, render him in three-quarter profile rather than straight-on so any mismatch reads as natural perspective rather than wrong-person.
- Adam's wardrobe: **plain matte-black short-sleeve T-shirt** with a small **circular speedometer-dial graphic** in vivid orange (#F26A1F) on the left chest — abstract, non-literal, no readable lettering. Black trousers or dark indigo jeans, plain black trainers. No visible brand names, no readable logos, no licence plate text, no watermarks.
- "Photoreal documentary lifestyle photograph" — natural look, not catalogue staged. Cinematic but not glossy. Some grain. Sharp focus on the two figures, gentle natural depth of field on the background.
- Lighting language is **the same across all four** so the set reads as one campaign: warm directional key light from one side, soft cool fill from the opposite side, deep but not crushed shadows. Slight orange / sodium tint in the highlights to echo the brand palette.
- **1:1 square aspect ratio.** Frame both people at roughly waist-up. Centre the prize between or just in front of them.
- Both subjects clearly **smiling and looking at the camera or at the prize** — celebratory but composed, not goofy.
- **No text, no logos, no readable brand names, no readable licence plate text, no watermarks** anywhere in the image.
- Photoreal, ultra-detailed, 1:1 square.
